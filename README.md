# JDC Portfolio Timeline

This is a portfolio site built with TailwindCSS and designed for GitHub Pages hosting.

## Features
- Timeline-style layout
- Dynamic GitHub repo embeds
- Sections for current roles, projects, and bio

## How to Deploy
1. Push your changes to the `main` branch.
2. In your repository settings, set GitHub Pages to serve from the `main` branch (root).
3. Your site will be live at https://jdc20181.github.io/

## Customization
- Edit `index.html` to update your bio, roles, projects, and timeline.
- GitHub repo embeds are automatically fetched from your public repos.
